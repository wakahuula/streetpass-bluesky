StreetPass for Bluesky

Privacy policy

Last updated November 19, 2026.

StreetPass for Bluesky is a browser extension for Chrome and Firefox. This page lists what data it reads, where that data goes and what it keeps on your device. The extension has no server of its own, and its developer receives no data from it.

What the extension reads

  • The address of each http or https page you open, to check whether the site's domain is a Bluesky handle and to show who is on the current page.
  • Links on that page marked rel="me" that point to a Bluesky profile.

It reads nothing else on the page: no text, no forms, nothing you type.

Where data goes

  • The site you are on. The extension asks it for /.well-known/atproto-did, the file that marks a domain as a Bluesky handle.
  • Bluesky's public API (public.api.bsky.app, run by Bluesky Social PBC). The extension sends the handle or ID of an account it found and gets its profile back. It never sends the page address. When you open the popup, it refreshes profiles older than an hour.
  • Bluesky's image server (cdn.bsky.app). The popup loads profile pictures from there, so Bluesky sees your IP address and which pictures were loaded.
  • Cloudflare (cloudflare-dns.com), only if you turn on "Look up handles in DNS". The extension then sends the domain of every https site you visit, except the ones you excluded, to Cloudflare's DNS resolver. Cloudflare's resolver privacy policy applies.

No request carries cookies. Like any web request, each one carries your IP address.

What stays on your device

  • Until you remove it: each person found (Bluesky ID, handle, display name, profile picture address, the domain they were found on, when, and whether the domain is their handle), your settings, the domains you excluded, and the count of new people.
  • Until the browser closes: the domains and accounts checked in the last 24 hours with their result, and who is on the page in each open tab.

Nothing is synced through your browser account. "Clear all" in the popup deletes the list, and removing the extension deletes everything.

What the extension doesn't do

No analytics, no ads, no account, and no selling or sharing of data. It doesn't load code from anywhere at runtime.

This website

The website runs on GitHub Pages. GitHub may log the IP addresses of visitors, as described in the GitHub privacy statement. The site sets no cookies, runs no analytics and loads nothing from other servers. The download buttons lead to GitHub.
